# Contributing to MedRadar 🏥

First off, thank you for considering contributing to MedRadar! It's people like you that make MedRadar such a great tool for healthcare professionals in Tier 2/3 cities.

## 🌈 Code of Conduct

By participating in this project, you are expected to uphold our Code of Conduct:
- Be respectful and inclusive.
- Use welcoming and inclusive language.
- Be collaborative and open to feedback.
- Focus on what is best for the community.

## 🚀 How Can I Contribute?

### Reporting Bugs
If you find a bug, please open an issue and include:
- A clear, descriptive title.
- Steps to reproduce the bug.
- Expected vs. actual behavior.
- Screenshots if applicable.
- Your environment (OS, Browser version, etc.).

### Suggesting Enhancements
We love new ideas! To suggest an enhancement:
- Check if the idea has already been suggested.
- Open an issue with a "feature request" tag.
- Explain why this feature would be useful for hospital resource management.

### Pull Requests
1. **Fork** the repository and create your branch from `main`.
2. **Setup** the project locally following the [README.md](README.md) instructions.
3. **Commit** your changes with clear, descriptive commit messages.
4. **Push** to your fork and submit a **Pull Request**.
5. **Review**: Wait for feedback and be prepared to make adjustments.

## 🎨 Style Guide

### Code Style
- Use **ESLint** for linting.
- Follow the existing architectural patterns in the `app/` and `components/` directories.
- Ensure your code is well-commented and easy to understand.
- Use functional components with hooks for React logic.

### UI/UX Consistency
- Use **Tailwind CSS** for styling.
- Follow the established color palette and typography.
- Ensure all components are responsive and accessible.
- Maintain the "modern and clean" healthcare aesthetic.

## 🛠 Areas for Contribution
- **Backend**: API development, database optimization, and security.
- **AI/ML**: Demand forecasting and resource optimization models.
- **Frontend**: Dashboard enhancements and data visualization.
- **IoT**: Integration with hospital hardware.
- **Documentation**: Improving guides and adding technical specs.
